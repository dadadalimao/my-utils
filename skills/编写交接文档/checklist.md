# 交接文档交付前检查清单

完成文档后逐项勾选。未勾选项需在文档中标注 `{待补}` 或 `{待确认}`。

## A. 阻塞接手（必须完成）

- [ ] 所有代码仓库有 **完整 URL**（后端 + 各前端）
- [ ] 生产 / 测试 / 开发 **各环境访问 URL** 齐全（含 API 域名）
- [ ] **接口文档** 有链接或明确获取方式（Apifox/Swagger/Postman）
- [ ] **Bug/需求系统** 有 URL + 账号申请联系人
- [ ] **CI 平台** 有地址 + 谁有权限看构建日志
- [ ] **测试账号** 说明获取方式（管理后台、小程序测试号、各角色）
- [ ] **运维/密钥负责人** 每个空角色有具体联系人
- [ ] **14 关键资源获取索引** 章节存在且非空

## B. 配置与启动（必须对照代码）

- [ ] Flyway/Liquibase **脚本实际路径** 与文档一致（含所在模块）
- [ ] 数据库迁移 **只在哪个服务启动时执行** 已说明
- [ ] 各环境 **数据库名** 已列出（dev/test/prod 可能不同）
- [ ] **Spring Profile / 环境切换** 方式已说明（不仅写 properties 文件名）
- [ ] 部署方式与 **CI 脚本一致**（jar+pm2 ≠ Docker 容器，勿混写）
- [ ] 服务器 **部署目录、pm2/systemd 进程名、回滚路径** 已写
- [ ] 本地 **IDE 运行配置**（多模块选哪个 module）已说明
- [ ] **本地最小启动组合**（改 admin 是否必须起 front）已说明
- [ ] 内网依赖（私有 Maven、内网 DB）已提醒

## C. 第三方与密钥（只写位置，不写值）

- [ ] 列出 **所有配置来源**：properties / DB 常量表 / 代码硬编码 / 证书文件 / CI Secrets
- [ ] 支付、OSS、短信、小程序等 **获取方式 + 负责人** 齐全
- [ ] 证书/私钥 **文件路径** 已列（不含内容）
- [ ] 微信支付 **回调地址** 在各环境如何配置已说明

## D. 运维与排障

- [ ] **日志路径**（应用 + Nginx/网关）已写
- [ ] **监控平台** 地址与告警方式已写
- [ ] **数据备份** 策略、频率、恢复方式已写或标注待补
- [ ] **回滚步骤** 可操作（非空）
- [ ] 定时任务 **所在服务** 已说明（多实例重复执行风险）

## E. 业务文档（按项目复杂度）

- [ ] 核心 **状态机** 或主流程已覆盖
- [ ] 关键 **定时任务** 表（Cron、启用状态）
- [ ] 关键 **接口速查** 或 Apifox 链接
- [ ] 已知 **技术债 / 硬编码 / 停用任务** 已标注

## F. 文档质量

- [ ] 无空表格行（无信息则写 `{待补}`）
- [ ] 路径、版本号、端口已与代码 **交叉验证**
- [ ] 文档版本号与更新日期已更新
- [ ] 无生产密码、Token、私钥明文

## 常见遗漏速查

| 易漏项 | 正确做法 |
|--------|----------|
| 只写 Apifox 不写链接 | 补项目 URL + 邀请方式 |
| Flyway 写在 dao 模块 |  grep `db/migration` 确认实际路径 |
| 部署写 Docker | 读 `.drone.yml` / workflow 看真实流程 |
| 配置只写 application.properties | 查 DB 常量表、Java 硬编码、证书目录 |
| 测试 API 域名缺失 | 与 admin-test 对应关系写清 |
| 前端部署方式缺失 | 补 CDN/OSS/静态服务器流程 |
| pay 等未使用模块 | 注明是否遗留/未引用 |
