# 清洗小说文本

分段原文保持不动。清洗结果只写到 `output/`。用户后续补充的规则追加到对应小节，并只对 `output/` 里的成书重跑该步骤。

默认用 PowerShell。读写使用无 BOM 的 UTF-8，换行保持 CRLF。

## 合并

只处理文件名匹配 `书名(起始-结束章).txt` 的分段文件。`output/` 里的成书不参与合并。

1. 按括号前的书名分组。
2. 按正文里第一个章节标题的章号排序，不要按文件名里的章节范围排序。文件名范围经常和正文不一致。
3. 章节标题是行首的 `第N章`。`N` 可以是阿拉伯数字或中文数字（含「零〇两」）。
4. 每段开头是书名、作者、来源、网址、空行。成书只保留第一段的这 5 行，后续段删掉同样的开头。
5. 每段结尾是空行和 `更多精彩小说，请访问：速读谷 http://www.suduguu.com`。拼接前删掉各段的这段结尾。
6. 段与段之间留一个空行，再接下一章标题。
7. 全文末尾补两个空行和上述站点行，只出现一次。
8. 写成 `output/书名.txt`。

PowerShell 函数若 `return` 一个 `List[string]`，调用方会得到展开后的 `Object[]`，后续 `AddRange` 会失败并写出空文件。在脚本内直接读写，不要把行列表从函数返回。

## 用字规则

对 `output/` 里的成书结合上下文检查，不把「幺」默认当作错字，不做全文无条件替换。本节取代原先「除老幺、幺蛾子外全部替换」的规则。

1. 保留「幺」的正常用法，包括「老幺」「幺蛾子」「幺弟」「幺妹」、数字读音、排行，以及人名、昵称、方言和专有名词，例如「竹幺妹」。不要只靠有限白名单决定其余「幺」都要替换。
2. 只有上下文明示是「什么」「怎么」「这么」「那么」等词的错写时，才逐处改成「么」。语境不明的保留，在聊天中说明疑点。
3. 修改前在当前会话中保留每处的章节或行号、原句和修改后句；完成后在聊天中逐项列出用字改动，便于核对和回退。没有用字改动也应说明。用户未要求时不另建日志或说明文档。
4. 复查历史清洗时，优先比对清洗前副本或逐处记录；没有记录时，只恢复上下文能确认的误改，不能把现有「么」批量反向替换为「幺」，也不能把推断当作已核实的历史改动。

## 错乱广告

广告行用中文或数字片段做锚点。一行命中任一锚点，整行删除。不根据问号、标点或其他符号判断，正文里的「????」和正常用词要留着。

## 重复标题

章节标题是行首的「第N章」，这一行本身没有缩进。若下一行去掉首尾空白（含全角空格）后与标题完全相同，删掉下一行。只处理紧挨着的这一行。

章号不同，或标题文字不完全相同的，先留着。

## 校验

合并后确认：

- 成书只有一处书名头、一处站点尾。
- 衔接处是上一段末句、一个空行、下一章标题，章号没有在衔接处倒退。
- 逐处复核用字改动的上下文，正常的「幺」用法保持不变；聊天中的原句、修改后句和定位信息齐全。
- 错乱广告锚点在成书中没有残留。正文里的问号、感叹和正常句子还在。
- 章节标题的下一行不再是同一行去掉缩进后的重复。
